# 运输船 T-09 · 实时 3D 团队竞技

穿越火线「运输船」的非官方 3D 同人复刻。整张地图、海面、货柜材质与枪械音效均为实时程序化生成，静态托管运行，无需后端。

## 操作
- WASD 移动，Shift 冲刺，Ctrl / C 蹲伏，Space 跳跃
- 左键射击，右键瞄准，R 换弹，G 手雷
- 1 / 2 切换主副武器，Tab 按住查看记分板，Esc 暂停
- 手机横屏：左侧虚拟摇杆，右侧拖动瞄准，右下角开火

## 说明
本地 4V4 团队竞技：玩家与 3 名 AI 队友对抗 4 名 AI 敌人，不连接真实玩家。
非官方粉丝作品，与 Smilegate / 腾讯无关。地图和 UI 为致敬性再创作。
